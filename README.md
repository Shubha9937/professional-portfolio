## 🚀 Quick Setup & Deployment to GitHub Pages

### Step 1: Create the GitHub Repository
1. Go to your GitHub account: [github.com/new](https://github.com/new)
2. Name the repository exactly: **`SHubha9937.github.io`**
3. Set the visibility to **Public**
4. Click **Create repository** (do not initialize with README if you are pushing these files directly).

### Step 2: Push the Code
In your terminal, navigate to this project folder:
```bash
git init
git add .
git commit -m "Initial commit of portfolio website"
git branch -M main
git remote add origin https://github.com/SHubha9937/SHubha9937.github.io.git
git push -u origin main
```

### Step 3: Enable GitHub Pages (Usually Automatic)
1. Go to your repository **Settings** -> **Pages**
2. Under **Build and deployment** -> **Source**, select **Deploy from a branch**
3. Choose branch `main` and folder `/ (root)`, then click **Save**.
4. In 1–2 minutes, your website will be live at:
   👉 **`https://shubha9937.github.io/`**
